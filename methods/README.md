# Methods

Target-neutral methodology and feasibility guidance. These documents contain
no target identifiers, no fixed sectors, no ephemerides, and no measured
results.

| Document | Purpose |
| --- | --- |
| `candidate-feasibility.md` | Seven-day go/no-go kill test template for new targets |
| `target-selection.md` | Neutral evaluation perspectives for comparing candidates |

Measured or decided values for a specific target belong in that target's
candidate workspace, never here.
