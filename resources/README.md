# Resources

Licensed, metadata-only, target-neutral resources.

Rules:

1. No arbitrary PDFs or full texts; prefer citation records and canonical
   links (arXiv, ADS, publisher DOI, archive identifiers).
2. No target-specific reading notes or bibliographies; those belong in
   `candidate/<candidate-id>/literature/`.
3. Every entry records provider, identifier, retrieval date, and license or
   terms.
